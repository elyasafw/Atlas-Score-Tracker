# Atlas Score Tracker

בקאנד לניהול טבלת תוצאות (Leaderboard) למשחקי ארקייד רטרו — Snake, Tetris ו-Space Invaders.
השרת שומר תוצאות ב-MongoDB Atlas וחושף API לשמירת תוצאות, טבלאות מובילים, פרופיל שחקן וסטטיסטיקות כלליות.

## מבנה הפרויקט

```
Atlas-Score-Tracker/
├── server.js
├── middleware.js
├── package.json
├── .env
├── models/
│   ├── connectDB.js
│   ├── dbService.js
│   └── controller.js
└── routes/
    └── routers.js
```

## התקנה והרצה

| שלב                                                   | פקודה                                     |
| -------------------------------------------------------- | ---------------------------------------------- |
| 1. התקנת תלויות                               | `npm install`                                |
| 2. יצירת קובץ`.env` בשורש הפרויקט | ראו טבלת משתני סביבה למטה |
| 3. הרצת השרת                                     | `node server.js`                             |

השרת יעלה על הפורט שהוגדר ב-`.env` ויתחבר אוטומטית ל-Atlas.

### משתני סביבה

| משתנה    | תיאור                              |
| ------------- | --------------------------------------- |
| `MONGO_URI` | connection string ל-cluster ב-Atlas   |
| `DB_NAME`   | שם מסד הנתונים              |
| `PORT`      | הפורט שעליו ירוץ השרת |

## Endpoints

| Method   | Path                   | תיאור                                                                                       |
| -------- | ---------------------- | ------------------------------------------------------------------------------------------------ |
| `POST` | `/games/scores`      | שמירת תוצאה חדשה                                                                   |
| `GET`  | `/leaderboard/:game` | 10 התוצאות הגבוהות ביותר במשחק ספציפי                              |
| `GET`  | `/leaderboard`       | 10 התוצאות הגבוהות ביותר בכל המשחקים יחד                         |
| `GET`  | `/player/:name`      | כל התוצאות של שחקן מסוים + הניקוד הכי טוב שלו בכל משחק |
| `GET`  | `/stats`             | סטטיסטיקות כלליות על כל התוצאות                                       |
| `GET`  | `/games`             | רשימת שמות המשחקים הקיימים (ללא כפילויות)                      |
